# Перегляд меблів (3D)

Міні-застосунок для замовників: 3D-модель шафи (або іншого виробу) з розмірами.
Працює як Telegram Mini App і як звичайна сторінка в браузері.

## Запуск

Потрібен Node.js 18+ (перевірено на Node 26).

```bash
npm install
npm run dev
```

Відкрийте адресу, яку покаже Vite (зазвичай http://localhost:5173).
Для перегляду з телефону в тій самій Wi-Fi мережі скористайтесь адресою `Network` з терміналу.

## Збірка

```bash
npm run build
npm run preview
```

Готовий сайт лежить у `dist/`. Це статичні файли: їх можна викласти на будь-який хостинг з HTTPS
(Netlify, Vercel, Cloudflare Pages, GitHub Pages). Telegram вимагає саме HTTPS.
Відкривати `dist/index.html` подвійним кліком не варто: браузер блокує модулі з `file://`.

## Як замінити дані

Виріб описується JSON-файлом у папці `data/`. Приклад: `data/sample-cabinet.json`.

- `unit` — лише `"mm"`.
- Кожна деталь у `parts`:
  - `w`, `h`, `d` — ширина (X), висота (Y), глибина (Z) у мм;
  - `x`, `y`, `z` — координати **лівого нижнього переднього** кута деталі;
  - `material` — ключ із `materials` (колір корпусу/фасаду).
- Вісь Y вгору. Фасади стоять із боку `z` більших значень (спереду).

Щоб змінити шафу, просто відредагуйте `sample-cabinet.json` і оновіть сторінку.

## Як додати нову модель

1. Створіть файл `data/cabinet-2.json` за зразком.
2. Відкрийте застосунок з параметром: `https://ваш-сайт/?model=cabinet-2`.

Назва моделі може містити лише латинські літери, цифри й дефіс.
Якщо файлу немає або JSON пошкоджено, замовник побачить зрозуміле повідомлення.

## Що вміє застосунок

- Обертання, наближення і віддалення мишею або пальцем (без панорамування, без перевертання).
- Натискання на деталь показує її назву й розміри внизу.
- «Показати розміри» — габаритний контур і підписи висоти, ширини, глибини.
- «Розібрати» / «Зібрати» — деталі плавно розходяться від центру.
- «Фасади: показані / приховані» — щоб бачити корпус.
- 6 готових кольорів фасадів (плюс колір з самого JSON).
- «Скинути вид» — повернути камеру у початкове положення.

Масштаб: 1 одиниця three.js = 1 мм.

## Підключення до Telegram

1. Задеплойте сайт на HTTPS і скопіюйте його адресу.
2. У Telegram напишіть `@BotFather`, виберіть `/mybots` → свого бота → **Bot Settings** → **Menu Button** → **Configure menu button**.
3. Вкажіть адресу сайту (з `?model=...`, якщо потрібна не шафа за замовчуванням) і назву кнопки.
4. Відкрийте бота, натисніть кнопку меню внизу — відкриється застосунок.

## Модель з БАЗИСу (рекомендовано)

1. У БАЗИСі збережіть модель як **COLLADA (*.dae)**. Поруч з'явиться папка `<назва>_textures`.
2. Перетворіть у стиснутий GLB (назва — латиницею, без пробілів):

   ```bash
   npm run convert -- "шлях\до\Модель.dae" nazva-modeli
   ```

   З'явиться `data/nazva-modeli.glb` (47 МБ .dae стискаються приблизно до 2 МБ).
   Конвертер відновлює назви деталей і кольори матеріалів, які губляться при експорті з БАЗИСу.
3. Відкрийте `?model=nazva-modeli`. Застосунок спершу шукає `.glb`, потім `.json`.

Стіни («Заміри → Стіна») можна сховати кнопкою «Стіни», фасади — кнопкою «Фасади».
Розміри показують габарит меблів без стін.

### Назва, префікс і замовлення з БАЗИСу

Перед експортом у .dae запустіть у БАЗИСі скрипт `Експорт для 3D-перегляду 1.0.js`
(`Scripts\1.Мої скріпти\CLAUDE\`). Він запише `m3-viewer.json` поруч із файлом моделі (назва, префікс і кріплення — шканти, конфірмати, яких у .dae немає).
Збережіть .dae у ту саму папку — конвертер сам підхопить назву й префікс, і в шапці буде «Санвузол · №480».

Повне замовлення часто містить ім'я клієнта, а сайт публічний, тому за замовчуванням воно не додається.
Щоб додати: `npm run convert -- "Модель.dae" nazva --with-order`.

### КП (комерційна пропозиція)

Покладіть PDF, назва якого починається на «КП» (наприклад, `КП_48.pdf`), у папку замовлення поруч із `.dae`.
`npm run convert` сам знайде його й зашифрує (AES-256): на сайт іде лише `data/<назва>.kp.bin`,
а ключ — у `keys/<назва>.txt` разом із готовим посиланням для клієнта (папка `keys/` у git не потрапляє).

Посилання для клієнта має вигляд `…/?model=<назва>#kp=<ключ>`. Без ключа КП не відкрити й кнопки «КП» не видно.
Окремо оновити лише КП: `npm run kp -- "шлях\до\КП.pdf" <назва>` (ключ лишається той самий, посилання не змінюється).

## Відправка замовнику (Telegram)

1. `npm run shot -- <назва>` — прев'ю моделі `data/<назва>.jpg` (потрібен запущений `npm run dev`).
2. Посилання для клієнта — у `keys/<назва>.txt`, рядок «Для клієнта в Telegram»:
   `https://t.me/m3_prodject_bot/view?startapp=<назва>__<ключ>`.
   Його можна надіслати будь-де (Telegram, Viber, SMS): Telegram одразу відкриє модель із КП.
3. Або гарною карткою: `npm run send -- <назва>` — бот надішле вам фото моделі, «Назва · №замовлення»
   і кнопку «Відкрити 3D-модель». **Перешліть цю картку замовнику** (можна «без імені відправника»):
   кнопка-посилання при пересиланні зберігається й відкриває модель із КП прямо в Telegram.

Бот не може написати людині першим, а кнопка міні-застосунку не працює в пересланих повідомленнях,
тому клієнту надсилаємо саме пряме посилання.

## Автоматично (без участі людини)

1. У БАЗИСі: заповнити «Параметри виробу» і зберегти модель (.b3d) у папку замовлення
   (там же має лежати `КП_….pdf`).
2. Запустити скрипт `Експорт для 3D-перегляду 1.8.js`. Він сам збереже .dae (недокументований
   `NewImportExport3D().SaveTo(Model, шлях)`), запише дані й відкриє вікно публікації
   (`M3-publish.bat`): конвертація → КП → сайт → очікування оновлення → прев'ю → картка в Telegram-бот.
3. Переслати картку з бота замовнику.

Якщо автозапуск не спрацював — перетягнути папку замовлення на `M3-publish.bat`. Хід роботи — у `publish-log.txt`.
Назва в посиланні береться автоматично: назва виробу латиницею + номер папки (`Санвузол` у `48.…` → `sanvuzol-48`).

## Швидка конвертація
`tools/dae-parse.mjs` розбирає .dae з БАЗИСу сам (≈2 с замість ≈20–50 с у assimp); результат звірено з assimp на моделях 46 і 48 — збігається вузол у вузол. Якщо розбір не впорається, конвертер сам переходить на assimp. Примусово assimp: `npm run convert -- "Модель.dae" назва --assimp`.

## Сповіщення «клієнт відкрив модель / КП / натиснув «Замовити»»
Сайт статичний, тож токен бота на нього класти не можна. Сповіщення йдуть через безкоштовний Cloudflare Worker (`notify-worker/`), де токен лежить секретом.
1. Зареєструватися на https://dash.cloudflare.com (безкоштовно).
2. `cd notify-worker` → `npx wrangler login` (відкриється браузер, підтвердити).
3. Далі розгортання й секрети (`BOT_TOKEN`, `CHAT_ID`) — `npx wrangler secret put …`, `npx wrangler deploy`.
4. Адресу воркера вписати в `src/notify.js` (`NOTIFY_URL`). Поки вона порожня — сайт нічого не надсилає.

## Відміна проєкту
`M3-cancel.bat` → ввести номер замовлення (або назву з посилання). Скрипт:
- прибирає картки, які бот надсилав тобі, і повідомлення бота клієнтам (до 48 год — видаляє, старіші — переписує на «не актуальна» без кнопки);
- видаляє з сайту модель, КП і прев'ю, додає назву в `data/revoked.json` — посилання показує «Доступ закрито»;
- ключі переносить у `keys/revoked/`.
Переслану тобою картку бот видалити не може, але кнопка в ній відкриє «Доступ закрито».

## Присадка (лише менеджеру)
Скрипт БАЗИС «Експорт для 3D-перегляду 1.5» вивантажує для кожної деталі контур і отвори (Holes: діаметр, глибина,
пласть А/Б, торець) у `m3-viewer.json` → конвертер шифрує їх у `data/<назва>.drill.bin` (AES-256-GCM,
ключ = HMAC-SHA256(токен бота, "m3-drill")). У модель (GLB) присадка не потрапляє.
Ключ видає воркер (`/drillkey`) лише за підписаними даними Telegram менеджера (CHAT_ID).
У перегляді: вибрати деталь → «Присадка · N» → креслення з розмірами від бази + список отворів.
